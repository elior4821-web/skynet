# העוזר הווירטואלי להוראה

אפליקציית Web מותאמת-מובייל ליצירת מערכי שיעור ומצגות למורים, עם בוט עוזר
הוראה מבוסס AI. מיועדת למדעים ומתמטיקה בכיתה ה', וגם למערכי שיעור בתוך המשחק
Minecraft Education.

## מבנה הפרויקט

- `server/` — Express API: יצירת תוכן באמצעות Claude (Anthropic), שמירת מערכי
  שיעור, העלאת חומרי מקור (PDF), וייצוא לקבצי PPTX / Word / PDF.
- `client/` — אפליקציית React (Vite), ממשק מותאם מובייל בעברית מימין-לשמאל.

## הפעלה מקומית

### 1. השרת (server)

```bash
cd server
npm install
cp .env.example .env   # ואז מלאו את ANTHROPIC_API_KEY אם יש לכם
npm run dev
```

השרת יעלה על `http://localhost:4000`. **בלי מפתח `ANTHROPIC_API_KEY`, נקודת
הקצה ליצירת תוכן עדיין עובדת אבל מחזירה תוכן דוגמה בלבד** — מוסיפים מפתח מתי
שרוצים, בלי לשנות קוד, ומקבלים תוכן אמיתי שנוצר על ידי Claude.

מפתח מקבלים בהרשמה בכתובת https://console.anthropic.com.

### 2. הלקוח (client)

בטרמינל נפרד:

```bash
cd client
npm install
npm run dev
```

האפליקציה תיפתח על `http://localhost:5173` ומתחברת אוטומטית לשרת המקומי
(פרוקסי מוגדר בקובץ `vite.config.js`).

## פיצ'רים

- **יצירת תוכן**: בחירת מקצוע (מדעים / מתמטיקה / Minecraft Education), סוג
  תוכן (מערך שיעור / מצגת), נושא, כיתה ומשך זמן — והבוט יוצר תוכן מובנה
  ומותאם לתכנית הלימודים של משרד החינוך.
- **חומרי מקור**: אפשר להעלות קבצי PDF (ספרי לימוד / תכניות לימודים רשמיות)
  לכל מקצוע. כשיוצרים תוכן חדש באותו מקצוע, הבוט משתמש בקטעים מהחומר שהועלה
  כדי לבסס את התשובה על התוכן האמיתי במקום רק על ידע כללי.
- **שמירה וניהול**: מערכי שיעור ומצגות שנוצרו נשמרים ברשימה מקומית לצפייה
  חוזרת ומחיקה.
- **ייצוא לקבצים**: מערכי שיעור ניתנים להורדה כ-Word (`.docx`) או PDF; מצגות
  ניתנות להורדה כקובץ PowerPoint (`.pptx`) עם שקפים לפי הכותרות שנוצרו.

## הערות טכניות

- אין מסד נתונים — מערכי השיעור וחומרי המקור נשמרים כקבצי JSON תחת
  `server/src/data/` (לא נכללים ב-git).
- אין מערכת התחברות/משתמשים בשלב זה — זהו כלי אישי ל-MVP.
- ייצוא ה-PDF משתמש בגופן Noto Sans Hebrew המצורף (`server/src/assets/fonts`)
  כדי לתמוך בעברית בלי תלות בגופנים שמותקנים על המכונה.
- הקוד הזה מריץ מקומית בלבד; לא בוצעה הפריסה (deployment) לאינטרנט.
